# Tashy Couture website starter

A responsive, static showcase website built with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best testing, use a local development server (for example VS Code Live Server).

## Before publishing
- Replace the TC text lockup in `index.html` with Tashy Couture's approved logo artwork (transparent SVG or PNG).
- Replace every image placeholder with approved, high-quality Tashy Couture photography.
- Confirm collection categories and bespoke services with Tashy.
- Replace draft About copy with Tashy's approved biography.
- Verify phone, email, location, and social links.
- Confirm Tashy owns and controls the domain registrar account.
- Do not change DNS until the new domain registration and any existing email/site services have been checked.

## WhatsApp

## Deploy to GitHub Pages
1. Create a GitHub repository, e.g. `tashy-couture`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. After GitHub Pages provides the site URL, test it on desktop and mobile.
5. Add the custom domain in GitHub Pages settings only after confirming domain ownership and DNS access.
6. Configure the registrar DNS records using GitHub's current instructions. Enable HTTPS once DNS has propagated.

## Notes
This is a first functional foundation, not a launch-ready final website. Placeholder blocks are intentional and should be replaced with real brand assets and approved content.
